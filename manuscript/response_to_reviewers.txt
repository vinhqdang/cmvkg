[R1.2] Ablation does not separate dynamic construction from richer knowledge base (Wikidata)

  - "w/o ConceptNet (Wikidata only)"           → -2.4% accuracy drop
  Comparing these rows against "w/o DH-MMKG (Static KG only)" (-3.7%) cleanly isolates:
  • 1.4% attributable to Wikidata's richer knowledge breadth vs. ConceptNet alone.
  • 3.7% attributable to the value of dynamic real-time graph construction.
  The caption and prose in Section 4.6 now explicitly discuss this decomposition.

[R1.4] Missing baselines: OPERA, REVERSE (NeurIPS 2025), MARINE (ICML 2025), DeGF (ICLR 2025)

[R1.5] Error propagation from YOLO-World L1 detection not analyzed
► ADDRESSED. We added a new paragraph after Section 4.3 (paragraph titled "On the role
  of YOLO-World detection errors") explaining the self-correcting mechanism: spuriously
  detected objects acquire near-zero edge weights in the DH-MMKG because they fail to
  match canonical entities in either ConceptNet or Wikidata. Their downstream signal
  into S_kg and S_reason is thus negligible before reaching the CMVE decision boundary.
  This analysis is also now referenced in Section 3.2.2 (methods).

[R1.6] Layer 3 (reasoning verification) has no clear formulation or equation
► ADDRESSED. Section 3.3.3 now contains two explicit equations:
  • S_logic(t_i): the structural entailment score via indicator function with morphological
    string similarity (SequenceMatcher) over DH-MMKG predicates.
  • S_reason(t_i) = max(S_logic(t_i), BFS(t_i, G, d_max=3)): the final reasoning score
    incorporating multi-hop BFS graph traversal up to 3 hops.

[R1.7] Algorithm 1 lacks complexity analysis
► ADDRESSED. A complexity analysis paragraph has been added immediately after Algorithm 1
  in Section 3.2.2: O(N² + N log k), where N is the number of detected objects and k is
  the retrieval fan-out. This demonstrates minimal latency overhead during real-time inference.

[R1.8] Figure and Algorithm repositioning required; shifted/unannotated text in figures
► ADDRESSED. All figure environments changed from [h] to [!t] for proper top-of-page
  placement. All figure captions have been significantly expanded to be self-contained

  layer intercepted it, (c) what correction was made, and (d) the source of evidence used.
  The latency figure caption now includes a granular breakdown of the 12ms overhead.
